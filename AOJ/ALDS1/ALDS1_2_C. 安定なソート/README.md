# [ALDS1] 安定なソート - ALDS1_2_C

[問題リンク](https://onlinejudge.u-aizu.ac.jp/courses/lesson/1/ALDS1/2/ALDS1_2_C)

## 実行結果 (Performance)
* 時間計算量 (Time Complexity): O(N^2)
* 実行時間 (Execution Time): 00.00 sec
* メモリ使用量 (Memory): 8488 KB

## 問題概要 (Description)
* 選択ソート、バブルソートを使って整列、この出力が安定か否かを出力
* 制約条件: 1 ≤ N ≤ 36

## 解法 (Approach)
* バブルソートが必ず安定なソートであることを知っていたら簡単に解決できる問題。
