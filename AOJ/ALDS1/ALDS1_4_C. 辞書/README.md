## 問題概要 (Description)
* 単語を保存して検索できる辞書を作りなさい。
* 制約条件: n ≤ 100,000、q ≤ 50,000、0 ≤ Sの要素, Tの要素 ≤ 10^9

## 解法 (Approach)
* pythonではsetを使ってset入力し、また検索すれば簡単に解決できる問題。だがC言語でするときは考えるのがもっと多い。
