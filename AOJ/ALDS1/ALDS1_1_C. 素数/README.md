# [ALDS1] 素数 - ALDS1_1_C

[問題リンク](https://onlinejudge.u-aizu.ac.jp/courses/lesson/1/ALDS1/1/ALDS1_1_C)

## 実行結果 (Performance)
* 時間計算量 (Time Complexity): O(N^0.5)
* 実行時間 (Execution Time): 00.15 sec
* メモリ使用量 (Memory): 8108 KB

## 問題概要 (Description)
* n 個の整数の中で素数の数を求める。
* 制約条件: 1 ≤ n ≤ 10,000、2 ≤ 与えられる整数 ≤ 10＾8

## 解法 (Approach)
* 合成数xはp<=x^0.5を満たす素因子pをもつから、x^0.5まで残りが0になる数があるかどうかの検査
