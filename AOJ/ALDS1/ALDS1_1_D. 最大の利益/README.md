# [ALDS1] 最大の利益 - ALDS1_1_D

[問題リンク](https://onlinejudge.u-aizu.ac.jp/courses/lesson/1/ALDS1/1/ALDS1_1_D)

## 実行結果 (Performance)
* 時間計算量 (Time Complexity): O(N)
* 実行時間 (Execution Time): 00.05 sec
* メモリ使用量 (Memory): 8200 KB

## 問題概要 (Description)
* n個の整数ように価値変動がある場合、最大の利益を求める。
* 制約条件: 2 ≤ n ≤ 200,000、1 ≤ R[t] ≤ 10＾9

## 解法 (Approach)
* 時間の流れによって価値が変動するから、最小値に買って最大値に売るようにします。
