# [ALDS1] スタック - ALDS1_3_A

[問題リンク](https://onlinejudge.u-aizu.ac.jp/courses/lesson/1/ALDS1/3/ALDS1_3_A)

## 実行結果 (Performance)
* 時間計算量 (Time Complexity): O(N)
* 実行時間 (Execution Time): 00.00 sec
* メモリ使用量 (Memory): 8256 KB

## 問題概要 (Description)
* 逆ポーランド記法で与えられた数式を計算しなさい。
* 制約条件: 2 ≤ 式に含まれるオペランドの数 ≤ 100、1 ≤ 式に含まれる演算子の数 ≤ 99、-1 × 10^9 ≤ 計算途中の値 ≤ 10^9

## 解法 (Approach)
* 数字をスタックに入れて演算しが出たらPOPして計算する。
