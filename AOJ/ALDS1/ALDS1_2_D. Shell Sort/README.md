# [ALDS1] Shell Sort - ALDS1_2_D

[問題リンク](https://onlinejudge.u-aizu.ac.jp/courses/lesson/1/ALDS1/2/ALDS1_2_D)

## 実行結果 (Performance)
* 時間計算量 (Time Complexity): O(N^1.25)
* 実行時間 (Execution Time): 07.88 sec
* メモリ使用量 (Memory): 48056 KB

## 問題概要 (Description)
* Shell Sortを使って整列、また交換回数を出力。
* 制約条件: 1 ≤ n ≤ 1,000,000、0 ≤ A[i] ≤ 10^9

## 解法 (Approach)
* Shell Sortは挿入ソートの応用、mとG[]はKnuthの数列を使って生成。
