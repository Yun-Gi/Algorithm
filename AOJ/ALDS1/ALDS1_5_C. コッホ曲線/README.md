# [ALDS1] コッホ曲線 - ALDS1_5_C

[問題リンク](https://onlinejudge.u-aizu.ac.jp/courses/lesson/1/ALDS1/5/ALDS1_5_C)

## 実行結果 (Performance)
* 時間計算量 (Time Complexity): O(4^N)
* 実行時間 (Execution Time): 00.00 sec
* メモリ使用量 (Memory): 8752 KB

## 問題概要 (Description)
* コッホ曲線の各頂点の座標 (x,y)を出力してください
* 制約条件: 0 ≤ n ≤ 6

## 解法 (Approach)
* 再帰的な関数の呼び出し解決する。コッホ曲線は座標を計算するとき数学的な公式が必要なのでそれに対して調べるのが必要でした。
