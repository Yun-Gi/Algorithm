# [ALDS1] 反転数 - ALDS1_5_D

[問題リンク](https://onlinejudge.u-aizu.ac.jp/courses/lesson/1/ALDS1/5/ALDS1_5_D)

## 実行結果 (Performance)
* 時間計算量 (Time Complexity): O(NlogN)
* 実行時間 (Execution Time): 00.49 sec
* メモリ使用量 (Memory): 31116 KB

## 問題概要 (Description)
* 反転数を求めなさい。
* 制約条件: 1 ≤ n ≤ 200,000、0 ≤ A[i] ≤ 10^9、 A[i]はすべて異なる値である。

## 解法 (Approach)
* 最初はバブルソートを利用してけいさんしましたが、時間制限に合うことができませんせした。もっと時間計算量が小さいソートを使うほうがいいと考えマージソートで変えました。
